## 1. 设计目标

| 目标 | 说明 |
|---|---|
| 单页化整合 | 原 5+ 个割裂静态页合并为单页应用，侧边栏导航无刷新切换 8 个模块 |
| 行业气质 | 深色「通信信号」视觉语言：青色信号主色、技术感等宽数字、网络/脉冲意象 |
| 数据即界面 | 数字滚动、趋势描线、环形分布、容量条，让仓储状态一眼可读 |
| 原型可信度 | 筛选标签真实过滤、表单弹窗可开合、实时时钟，模拟可交付的系统 |

## 2. 设计原则

1. **信息层级靠排版与色彩，而非边框堆砌** —— 数字用 Chakra Petch 大字号，辅助信息降饱和度灰。
2. **每个状态都有语义色** —— 待处理=琥珀、处理中=青、完成=绿、紧急/维护=红。
3. **动效服务于反馈** —— 进入揭示、描线、计数，全部可被 `prefers-reduced-motion` 关闭。
4. **零依赖** —— 纯 HTML/CSS/JS + SVG 图表，不引入任何 CDN 框架。

## 3. 设计令牌（Design Tokens）

### 3.1 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0a0e16` | 页面底色（深空黑蓝） |
| `--surface` | `#111725` | 卡片一级面 |
| `--surface-2` | `#161e2e` | 卡片悬停/输入框底 |
| `--surface-3` | `#1c2536` | 进度条轨道、滚动条 |
| `--border` | `rgba(148,163,184,.09)` | 常规描边 |
| `--border-hi` | `rgba(148,163,184,.18)` | 悬停描边 |
| `--text` | `#e8edf6` | 主文本 |
| `--text-2` | `#9aa5bb` | 次级文本 |
| `--text-3` | `#5c677d` | 弱化文本/标签 |

**语义色（每个含 12% 透明背景变体）：**

| 令牌 | 值 | 语义 |
|---|---|---|
| `--cyan` | `#22d3ee` | 主色：信号、处理中、入库趋势 |
| `--amber` | `#fbbf24` | 待处理、警告、出库趋势 |
| `--green` | `#34d399` | 完成、可用、在线 |
| `--red` | `#f87171` | 紧急、维护中、错误 |
| `--violet` | `#a78bfa` | 入库统计、基站设备 |

### 3.2 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 展示/数字 | **Chakra Petch** 500/600/700 | 页标题、统计大数字、分区代号 |
| 正文 | **Noto Sans SC** 400/500/700 | 全局中文正文 |
| 等宽 | **JetBrains Mono** 400/500 | 时钟、单号、序列号、坐标轴 |

字号阶梯：页标题 26 → 卡片标题 15 → 正文 13~14 → 辅助 12.5 → 标签 11 → 等宽小字 10~10.5。

### 3.3 尺寸与圆角

- 侧边栏宽 `248px`，顶栏高 `64px`
- 卡片圆角 `14px`、按钮 `10px`、状态胶囊 `20px`
- 栅格间距 `18px`，内容区左右留白 `28px`
- 统计卡数字 `34px`，环形图 `150px`
