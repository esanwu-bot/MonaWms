# MonaWMS 后端技术方案

## 一、技术栈选择

### 核心框架
- **Node.js** - 高性能JavaScript运行环境
- **Express.js** - 轻量级Web应用框架
- **TypeScript** - 提供类型安全，提高代码质量

### 数据库
- **MySQL 8.0** - 主数据库，存储业务数据
- **Redis** - 缓存数据库，会话存储和数据缓存

### ORM框架
- **Prisma** - 现代化数据库工具包，提供类型安全的数据库访问
- **Prisma Client** - 自动生成的类型安全数据库客户端

### 身份认证
- **JWT (jsonwebtoken)** - 无状态身份验证
- **bcrypt** - 密码加密
- **passport.js** - 认证中间件

### 数据验证
- **Joi** - 数据验证库
- **express-validator** - Express验证中间件

### 文件处理
- **multer** - 文件上传中间件
- **sharp** - 图像处理

### 日志管理
- **winston** - 日志记录库
- **morgan** - HTTP请求日志中间件

### 任务队列
- **Bull** - Redis基础的任务队列
- **node-cron** - 定时任务调度

### 核心数据表设计

#### 1. 用户管理表
```sql
-- 用户表
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    role ENUM('admin', 'manager', 'operator', 'viewer') DEFAULT 'operator',
    status ENUM('active', 'inactive') DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 角色权限表
CREATE TABLE permissions (
    id INT PRIMARY KEY AUTO_INCREMENT,
    role VARCHAR(50) NOT NULL,
    resource VARCHAR(50) NOT NULL,
    action VARCHAR(50) NOT NULL,
    allowed BOOLEAN DEFAULT TRUE
);
```

#### 2. 仓库管理表
```sql
-- 仓库表
CREATE TABLE warehouses (
    id INT PRIMARY KEY AUTO_INCREMENT,
    code VARCHAR(20) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    address TEXT,
    manager_id INT,
    status ENUM('active', 'inactive') DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (manager_id) REFERENCES users(id)
);

-- 库区表
CREATE TABLE zones (
    id INT PRIMARY KEY AUTO_INCREMENT,
    warehouse_id INT NOT NULL,
    code VARCHAR(20) NOT NULL,
    name VARCHAR(100) NOT NULL,
    zone_type ENUM('storage', 'picking', 'packing', 'staging') DEFAULT 'storage',
    FOREIGN KEY (warehouse_id) REFERENCES warehouses(id)
);

-- 货架表
CREATE TABLE shelves (
    id INT PRIMARY KEY AUTO_INCREMENT,
    zone_id INT NOT NULL,
    code VARCHAR(20) NOT NULL,
    name VARCHAR(100) NOT NULL,
    capacity DECIMAL(10,2),
    current_load DECIMAL(10,2) DEFAULT 0,
    FOREIGN KEY (zone_id) REFERENCES zones(id)
);

-- 库位表
CREATE TABLE locations (
    id INT PRIMARY KEY AUTO_INCREMENT,
    shelf_id INT NOT NULL,
    code VARCHAR(20) NOT NULL,
    barcode VARCHAR(50),
    status ENUM('available', 'occupied', 'reserved', 'blocked') DEFAULT 'available',
    FOREIGN KEY (shelf_id) REFERENCES shelves(id)
);
```

#### 3. 商品管理表
```sql
-- 商品分类表
CREATE TABLE categories (
    id INT PRIMARY KEY AUTO_INCREMENT,
    parent_id INT,
    code VARCHAR(20) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    FOREIGN KEY (parent_id) REFERENCES categories(id)
);

-- 商品表
CREATE TABLE products (
    id INT PRIMARY KEY AUTO_INCREMENT,
    sku VARCHAR(50) UNIQUE NOT NULL,
    name VARCHAR(200) NOT NULL,
    category_id INT,
    barcode VARCHAR(50),
    unit VARCHAR(20) DEFAULT 'pcs',
    weight DECIMAL(8,3),
    volume DECIMAL(8,3),
    min_stock INT DEFAULT 0,
    max_stock INT DEFAULT 0,
    status ENUM('active', 'inactive') DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

#### 4. 库存管理表
```sql
-- 库存表
CREATE TABLE inventory (
    id INT PRIMARY KEY AUTO_INCREMENT,
    product_id INT NOT NULL,
    location_id INT NOT NULL,
    batch_no VARCHAR(50),
    quantity INT NOT NULL DEFAULT 0,
    reserved_quantity INT DEFAULT 0,
    available_quantity INT GENERATED ALWAYS AS (quantity - reserved_quantity) STORED,
    production_date DATE,
    expiry_date DATE,
    last_updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (product_id) REFERENCES products(id),
    FOREIGN KEY (location_id) REFERENCES locations(id),
    UNIQUE KEY unique_product_location_batch (product_id, location_id, batch_no)
);

-- 库存变动记录表
CREATE TABLE inventory_transactions (
    id INT PRIMARY KEY AUTO_INCREMENT,
    product_id INT NOT NULL,
    location_id INT NOT NULL,
    transaction_type ENUM('inbound', 'outbound', 'transfer', 'adjustment') NOT NULL,
    quantity_change INT NOT NULL,
    quantity_before INT NOT NULL,
    quantity_after INT NOT NULL,
    reference_type ENUM('inbound_order', 'outbound_order', 'transfer_order', 'adjustment') NOT NULL,
    reference_id INT NOT NULL,
    operator_id INT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (product_id) REFERENCES products(id),
    FOREIGN KEY (location_id) REFERENCES locations(id),
    FOREIGN KEY (operator_id) REFERENCES users(id)
);
```

#### 5. 入库管理表
```sql
-- 入库单表
CREATE TABLE inbound_orders (
    id INT PRIMARY KEY AUTO_INCREMENT,
    order_no VARCHAR(50) UNIQUE NOT NULL,
    supplier_id INT,
    warehouse_id INT NOT NULL,
    status ENUM('pending', 'receiving', 'quality_check', 'completed', 'cancelled') DEFAULT 'pending',
    expected_date DATE,
    received_date DATE,
    operator_id INT,
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (warehouse_id) REFERENCES warehouses(id),
    FOREIGN KEY (operator_id) REFERENCES users(id)
);

-- 入库单明细表
CREATE TABLE inbound_order_items (
    id INT PRIMARY KEY AUTO_INCREMENT,
    inbound_order_id INT NOT NULL,
    product_id INT NOT NULL,
    expected_quantity INT NOT NULL,
    received_quantity INT DEFAULT 0,
    quality_checked_quantity INT DEFAULT 0,
    rejected_quantity INT DEFAULT 0,
    batch_no VARCHAR(50),
    production_date DATE,
    expiry_date DATE,
    FOREIGN KEY (inbound_order_id) REFERENCES inbound_orders(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);
```

#### 6. 出库管理表
```sql
-- 出库单表
CREATE TABLE outbound_orders (
    id INT PRIMARY KEY AUTO_INCREMENT,
    order_no VARCHAR(50) UNIQUE NOT NULL,
    customer_id INT,
    warehouse_id INT NOT NULL,
    status ENUM('pending', 'picking', 'packing', 'shipped', 'delivered', 'cancelled') DEFAULT 'pending',
    priority ENUM('low', 'normal', 'high', 'urgent') DEFAULT 'normal',
    required_date DATE,
    shipped_date DATE,
    operator_id INT,
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (warehouse_id) REFERENCES warehouses(id),
    FOREIGN KEY (operator_id) REFERENCES users(id)
);

-- 出库单明细表
CREATE TABLE outbound_order_items (
    id INT PRIMARY KEY AUTO_INCREMENT,
    outbound_order_id INT NOT NULL,
    product_id INT NOT NULL,
    required_quantity INT NOT NULL,
    picked_quantity INT DEFAULT 0,
    packed_quantity INT DEFAULT 0,
    shipped_quantity INT DEFAULT 0,
    FOREIGN KEY (outbound_order_id) REFERENCES outbound_orders(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);
```

## 四、API接口设计
